To use you must have your own iso and your own VB file for radio the radio replacement and with that you can even modify the DTZ and GXT files for a new radio name and radio logo and the patcher will load them alongside the vb if chosen from a folder

This Project is used for research towards an AIO application and VB's, DTZ's and GXT's can be made/edited from the AIO project here https://github.com/KaylaD23/GTA-Modding-Studio
